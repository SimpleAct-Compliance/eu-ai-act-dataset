# Contributing

Corrections and additions are welcome.

- Open an issue or a pull request and cite the article, ideally with a link to EUR-Lex.
- Change the JSON file and the YAML twin together. For dates, edit `data/deadlines.json` and run `node scripts/build-ics.mjs`.
- Run `node scripts/validate.mjs` before you push.
- Keep both languages. If you can only write one, say so in the pull request and we add the other.

Texts are summaries for orientation. Please do not paste the wording of the regulation.
